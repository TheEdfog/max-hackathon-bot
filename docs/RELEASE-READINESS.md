## Реализовано

- Сквозной чат-сценарий: работодатель, вакансия, ручное подтверждение требований, ссылка, согласие кандидата, текст опыта, до трёх уточнений, карточка с цитатами, приглашение, подтверждение, отзыв.
- Кнопки, страницы списков, восстановление незаконченного отклика, сводка работодателя. Нет автоматического ранжирования/отказов. Пропуск уточнения не превращается в «нет опыта».
- `/demo`: восемь помеченных учебных шагов для одного аккаунта; синтетика, без изменения реальных вакансий/ролей.
- Изоляция работодателей, ограничения входа, валидация webhook/JWT/MAX initData, дедупликация, транзакции изменений, очередь с ограниченными повторами. Отзыв очищает тексты отклика и связанные серверные копии.
- PDF API: отдельный ограниченный процесс без унаследованных ключей. Основной MAX-сценарий принимает текст, не вложения.
- Минимальный Docker runtime, pinned зависимости, Caddy/HTTPS-конфигурация, команды настройки webhook, диагностики, резервного копирования, тестовых аккаунтов и удалённого DATA-API прогона.

## Соответствие кейсу

Повторно прочитаны страницы 7–14 предоставленного «Эффективный бизнес.pdf». Обязательная форма — работающий сценарий в MAX, исходники с фиксированной версией, README, Docker, зависимости и PDF-презентация; для своего API также HTTPS, OpenAPI, роли/тестовые данные, DATA-API.

## Что остаётся вне автоматической проверки

1. Яндекс Cloud: реальный домен/HTTPS, секреты, один webhook, отключение локального polling, backup/мониторинг; замена `api.baseUrl` и удалённый DATA-API прогон. Порядок готов в [DEPLOYMENT.md](DEPLOYMENT.md).
2. Обязательная PDF-презентация; чувствительные технические доступы нельзя публиковать в открытом GitHub.
3. Ручная проверка мобильного и веб-MAX. У команды пока один доступный аккаунт: `/demo` помогает репетиции, но настоящий обмен работодатель↔кандидат двумя аккаунтами пока не подтверждён.
4. Пользователь сообщил о согласии Вадима. Условия повторного использования, допустимость основы и срок доступности стенда команда подтверждает у организаторов; лицензию от имени Вадима не выдаём.

До согласования оператора данных — только синтетические резюме. Текущий релиз рассчитан на один экземпляр SQLite; не заявляются проверенная высоконагруженность, SLA, exactly-once доставка или промышленная готовность для реального найма.
