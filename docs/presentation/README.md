# Презентация the_swarm

`the_swarm_MAX_final.pptx` - редактируемая версия с текстом выступления и источниками в заметках докладчика. `the_swarm_MAX_final.pdf` - версия для просмотра и передачи. Снимок реализации: `3aa7eaa9b9cff539c2544145727273b9fc792787` (1.5.0). Файлы презентации добавляются последующим документационным commit; это не новая версия алгоритма.

17 слайдов: первый служебный, слайды 2-12 для пяти минут, слайды 13-17 для вопросов. В PowerPoint можно начинать показ со слайда 2. В PDF заметки докладчика не отображаются.

## Перед технической сдачей

Публичная версия не содержит ключей и паролей. На первом слайде честно отмечено отсутствие публичного HTTPS. После размещения нужен отдельный закрытый комплект для комиссии: реальный HTTPS, финальный замороженный commit, тестовые аккаунты, безопасно переданное окружение и инструкция. Поле DATA-API нельзя оставлять `deployment-required.invalid`. Не публикуйте закрытую версию с доступами в Git.

Дедлайн по FAQ: 30 сентября, 12:00 МСК. Версия после сдачи фиксируется, бот остаётся доступным весь период проверки. [Разбор рисков](../FAQ-AUDIT-2026-09-28.md) обязателен к обсуждению командой, особенно значительный объём AI-помощи и повторное использование прежней основы. Презентация сама по себе не решает вопрос допуска.

Гипотеза 30% экономии обозначена как цель пилота. 298 тестов - функциональные автоматические проверки, не процент точности найма. Конкретного клиента, подтверждённой выручки и сертифицированной коммерческой ATS-интеграции пока нет. Тестовые резюме на слайдах вымышленные.
