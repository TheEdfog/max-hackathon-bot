# MAX web: тесты и импорт 1.3, 27.09.2026

Проверено в реальном web.max.ru, существующий чат бота, один разрешённый физический аккаунт и виртуальные роли отдельной SQLite-песочницы. Синтетические вакансия и ответы; публичный GitHub владельца использован с его разрешения. Настоящий найм, рассылки и приглашения посторонним не выполнялись.

Успешный путь:

1. Меню работодателя показывает «Библиотека тестов».
2. «Создать тест»: название, один SQL-вопрос и закрытый критерий после `||`; подтверждение сохранения.
3. Новая синтетическая вакансия с SQL. «Тест для вакансии» показывает библиотеку, выбранный шаблон подтверждается, вакансия публикуется в песочнице.
4. Роль кандидата открывает опубликованную ссылку и подтверждает обработку тестовых сведений.
5. Отправка `https://github.com/TheEdfog` запускает worker. Получены пять публичных репозиториев, языки файлов и описания; предупреждение о недоказанном личном вкладе отображается.
6. До подтверждения видны «Прочитать полностью» и «Использовать для отклика». Полный текст открывается отдельным сообщением. Отклик создаётся только после подтверждения.
7. Бот задаёт уточнение SQL, затем сохранённое задание. Закрытого критерия в сообщении кандидату нет, кнопка «Опыта нет» не показывается для задания. Ответ сохранён, уведомление работодателю пришло.
8. Работодатель открывает карточку, «Ответы на тест» показывает вопрос и ответ без обрезки; критерий приходит отдельным сообщением с предложением ручной проверки.

Управление кнопками проверено через клавиатурную активацию доступных элементов. Одна повторная активация уже использованного меню дала ожидаемое «Кнопка устарела»; после получения актуального ответа сценарий продолжился. Веб-клиент доставляет ответы асинхронно, краткое отсутствие ответа сразу после нажатия не считается ошибкой бота.

После проверки обычный polling возвращён без sandbox-флагов. Перед работой создан локальный backup; реальные вакансии/пользователи/отклики не использовались для сценария.

Не проверено этим прогоном: мобильный клиент, независимые MAX-аккаунты, Google/Yandex share-link, Mail.ru download (не реализован). Безопасность владения, отзыв PDF/заметок, отмена импорта в момент скачивания и фиксация версии теста отдельно покрыты автотестами.
