# Функции и план упрощения

> Исторический документ до упрощения 1.7. Актуальный состав и ограничения: [SIMPLIFIED-1.7.md](SIMPLIFIED-1.7.md). Упомянутые здесь LLM, GitHub, ATS-заметки и проценты больше не входят в runtime.

## Что уже работает

| Блок | Возможности | Ограничения |
|---|---|---|
| Работодатель в MAX | Вход по коду, создание вакансии, проверка требований, ссылка отклика, закрытие вакансии | Отдельного веб-кабинета больше нет |
| Кандидат в MAX | Согласие, текст опыта, уточнения навыков, пропуск, пауза и продолжение, отзыв отклика | Вложения MAX, OCR и DOCX не реализованы |
| Сопоставление | Общий словарь IT, аналитики, управления и продаж; синонимы, отрицания, прямые и косвенные признаки, цитаты | Локальные правила, не обученная ML-модель и не подтверждение квалификации |
| Карточка и решение | Ответы, цитаты, ожидания; ручное приглашение и подтверждение кандидатом | Нет автоматического отказа или решения о найме |
| Короткое интервью | По выбору работодателя вопросы об интересе, условиях и сроке выхода | Отдельно от вопросов о навыках |
| Тесты вакансии | Библиотека до трёх заданий, закрытые критерии, версии, неизменяемая копия у вакансии | Проверка ответов человеком |
| Резюме и источники | Текст; PDF через API или поддержанную публичную ссылку Яндекс Диска; выдача оригинала PDF и текста HR-системе | PDF с текстовым слоем, 5 МБ/10 страниц; не произвольный веб-парсинг |
| GitHub | По запросу рекрутера: публичный профиль, метаданные и README до пяти репозиториев; кэш | Не читает весь код, не доказывает авторство и не влияет на оценку |
| Покрытие требований | Отдельный отчёт must/nice с формулой, слагаемыми и цитатами | Не вероятность найма и не рейтинг людей |
| HR API | Ключи с правами и отзывом, вакансии по внешнему ID, отклики, PDF/текст, приглашения, метрики, лента изменений | Универсальный контракт и пример адаптера, не готовый сертифицированный коннектор к ATS |
| Внутренняя работа HR | Ручные этапы, заметки и метки, защита от перезаписи устаревшей версии | Этапы не отправляются кандидату как автоматические решения |
| Черновик вакансии из резюме | Выделение профессиональных навыков без публикации, обязательная проверка работодателем | Только HR API; не заменяет формулировку потребностей бизнеса |
| AI-черновики вопросов | Cloud.ru, DeepSeek, OpenAI-compatible или отключение; квоты, кэш, локальный шаблон при сбое, бесплатный запрос статуса | Только HR API; только канонические навыки и уровень, без резюме/переписки; нет кнопки AI-генерации в MAX |
| Сводка | Число вакансий и откликов по состояниям, только своей компании | Не аналитическая BI-система |
| Демонстрация и разработка | Учебный `/demo` на синтетике; отдельная development-песочница с виртуальными ролями | `/demo` не заменяет приёмку двумя аккаунтами; песочница запрещена в production |
| Эксплуатация | Docker, webhook, диагностика, резервное копирование, очередь, дедупликация, локальные и контейнерные тесты | Публичный сервер и удалённые проверки ещё не подтверждены |

Google Drive и Mail.ru отключены до согласования документированного способа интеграции. Прежний веб-интерфейс, веб-демо и дублирующий Dockerfile уже удалены. Презентация пока фиксирует версию 1.5.

## Приоритет на удаление или сокращение

Номер 1 - первый кандидат. Приоритет учитывает ясность сценария, обслуживание и риск регрессии, а не только количество строк.

| № | Что сократить | Почему | Что потеряем / как поступить |
|---|---|---|---|
| 1 | Неактивные обходные адаптеры Google Drive/Mail.ru | В конкурсной версии не работают, усложняют объяснение поддерживаемых источников | Удалить реализации, оставить понятный ответ «источник не поддерживается» и защитные тесты |
| 2 | Черновик вакансии из резюме | Обратный сценарий уводит от задачи работодателя и дублирует извлечение навыков | Удалить специализированный endpoint после проверки потребителей; оставить обычное создание вакансии |
| 3 | GitHub-обзор | Узкая польза для части IT-вакансий, внешняя сеть, очередь и кэш | Убрать из основного релиза, если нет убедительного пилота; ссылка в резюме останется доступна рекрутеру |
| 4 | Попытку заменить полноценную ATS | Шесть этапов, метки и заметки пересекаются с платформой интегратора | Оставить короткую заметку/шорт-лист и экспорт; не убирать контроль версий, если совместное редактирование остаётся |
| 5 | Отдельный процент «покрытия» | Частично повторяет карточку доказательств и может восприниматься как точность оценки человека | Убрать дополнительную кнопку/процент; сохранить прямые и косвенные признаки, цитаты и объяснения |
| 6 | AI-генерацию вопросов | Основной отбор без неё работает; добавляет ключи, расходы и сетевые сбои | Вначале просто отключить в конфигурации. Удалять код только после решения команды; провайдерская настройка уже изолирована |
| 7 | Импорт с Яндекс Диска | Ещё одна внешняя зависимость | Убирать только если устраивает более длинный путь подачи текста/PDF через API; PDF-выгрузку для HR сохранить |
| 8 | Повторно используемую библиотеку тестов | Увеличивает число экранов по сравнению с тестом одной вакансии | Низкий приоритет: переиспользование полезно работодателю. Можно скрыть управление библиотекой за дополнительной кнопкой; неизменяемый снимок теста сохранить |

Неиспользуемые части старой разработки стоит вынести в архив исходной основы, но не удалять каталоги целиком без анализа импортов: текущий runtime использует `core/utils.py` и `apps/web/services/vacancy_parser_service.py`. Атрибуцию Вадима и историю происхождения сохранять.

## Что оставить в компактной конкурсной версии

1. Вакансия и подтверждённые требования.
2. Согласие кандидата, опыт, короткие уточнения, пауза и отзыв.
3. Карточка с цитатами и ручное приглашение.
4. Короткий тест вакансии с закрытыми критериями и стабильной копией.
5. Минимальный HR API: вакансии, отклики, резюме, приглашение и события отзыва.
6. Учебный сценарий, сводка, HTTPS, Docker и проверяемая эксплуатация.

Не сокращать изоляцию работодателей, права доступа, ограничения PDF/URL, обработку отзыва, дедупликацию, резервное копирование и тесты. Первым шагом рекомендую пункты 1-3 таблицы; остальные - только после выбора команды. В рамках этого отчёта ничего из таблицы не удалено.
