# Проверка в MAX за 5 минут

Бот: https://max.ru/t781_hakaton_max_bot. Пока он запущен локально, компьютер должен оставаться включённым и не переходить в сон.

## Сейчас есть один аккаунт

1. Отправить `/start`, нажать «Учебный сценарий» (или отправить `/demo`). Код работодателя не нужен.
2. Подтвердить учебные требования и перейти к роли кандидата.
3. Продолжить на вымышленных данных. Убедиться: Python найден в тексте, для Docker задан вопрос.
4. Выбрать «Опыта нет» или пропуск. В карточке должны быть разные результаты: отсутствие опыта и недостаток сведений не смешиваются.
5. Подготовить учебное приглашение, посмотреть его глазами кандидата, подтвердить интерес.
6. Выйти из демо. Настоящая роль и бизнес-записи остаются прежними.

Это репетиция. Она действительно использует кнопки MAX и движок сопоставления, но не создаёт реальный отклик и не доказывает межаккаунтную доставку. До сдачи нужен следующий прогон.

## Два аккаунта: настоящий основной сценарий

Работодатель: `/start` → «Я работодатель» → код из локальной `.env.hiring` (HIRING_EMPLOYER_CODE) → название компании. Код не публиковать и не пересылать кандидатам.

«Новая вакансия»: `Junior Python-разработчик` и описание:

> Разрабатываем внутренний каталог. Обязательны Python и PostgreSQL. Будет плюсом Docker. Удалённая работа, условия обсудим на интервью.

Проверить список требований, при необходимости заменить его тремя строками `Python`, `PostgreSQL`, `+Docker`. Нажать «Публиковать» и передать ссылку второму аккаунту.

Кандидат: открыть ссылку → согласие → отправить:

> Я разработал на Python учебный каталог книг, написал тесты и документацию. Работал через Git, делал ветки и исправлял ошибки. Другие технологии в этом примере не описаны.

Ответить на уточнения: например, про PostgreSQL — «Спроектировал в PostgreSQL таблицы книг и написал JOIN-запросы», про Docker — «Опыта нет».

Работодатель: уведомление → карточка → цитаты и ответы → «Пригласить» → `Приглашаем обсудить ваш учебный проект завтра в 15:00. Напишите удобное время в MAX.`

Кандидат: «Подтвердить интерес». Работодатель: уведомление и `/metrics` показывают подтверждение. Затем кандидат может отозвать отклик; карточка больше недоступна работодателю.

Повторить в мобильном и веб-MAX. Результаты фиксировать в [ACCEPTANCE.md](ACCEPTANCE.md), не по автотестам.

## Если нет ответа

1. Проверить, что локальный процесс запущен (`RUN-BOT.cmd`), компьютер не спит. Не запускать второй экземпляр.
2. `python -m hiring.doctor --max` — диагностика без содержимого сообщений и секретов.
3. Для устаревшей кнопки открыть `/start`; для незаконченного отклика — «Мои отклики» → «Продолжить уточнения».
4. Отправить команде время ошибки и действие, но не токен, код работодателя или реальные резюме.
