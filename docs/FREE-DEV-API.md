# Бесплатные модели как ограниченный помощник разработчика

Каталог [awesome-free-llm-apis](https://github.com/mnfst/awesome-free-llm-apis) используется для поиска доступных провайдеров, а не как гарантия доступности, цены или конфиденциальности. Производственный бот не зависит от внешней модели и не отправляет ей резюме.

`scripts/free_dev_draft.py` принимает только вручную подготовленный короткий текст через stdin. По умолчанию — dry-run; отправка требует `--send`, смена провайдера после ошибки — отдельного `--fallback`. Разрешены OVH anonymous Qwen3-Coder и Kilo `kilo-auto/free`, без ключей, аккаунтов и платного fallback. Переключение — максимум один раз, без циклических повторов, обхода квот или смены IP.

```sh
python scripts/free_dev_draft.py --data-class synthetic
python scripts/free_dev_draft.py --data-class synthetic --provider ovh --send --fallback
```

Введите маленькое синтетическое задание и завершите stdin. Лимиты: 4 000 входных символов, 800 выходных токенов, 25 секунд на провайдера, ограниченный размер ответа. Редиректы запрещены. Нет чтения файлов/окружения, отправки истории чата, запуска или автоматического применения полученного кода. Ответ помечен `untrusted_draft`; любой код требует локальной проверки. Простой фильтр блокирует очевидные ключи/email, но **не заменяет ручное обезличивание**.

Разрешённые задачи: автономная чистая функция, синтетические тестовые случаи, краткий черновик документации по публичному контракту. Не отправлять личную переписку, резюме, конфиденциальный код, БД, `.env`, токены и контакты. Авторизация, персональные данные и решения о найме не делегируются внешнему черновику.

Официальные источники: [OVH AI Endpoints](https://docs.ovhcloud.com/en/guides/public-cloud/ai-machine-learning/ai-endpoints-getting-started), [Kilo authentication](https://kilo.ai/docs/gateway/authentication), [Kilo free models](https://kilo.ai/docs/getting-started/using-kilo-for-free). У downstream-провайдеров бесплатных моделей возможны логирование/обучение на запросах — это ещё одна причина использовать только синтетический или разрешённый публичный материал.

## Фактический результат

Ранее получен один короткий успешный OVH-черновик, провайдер сообщил 334 токена; это не измерение экономии Codex ([SANDBOX.md](SANDBOX.md)). В текущей разработке API обращения к OVH и Kilo завершились сетевой/response-ошибкой; каталог моделей Kilo также не ответил вовремя. Неудачный ответ не применялся. После ограниченных попыток работа продолжена локально. Экономия токенов не заявляется без измерений; постоянные повторы могли бы увеличить расходы самой сессии.

Практическая экономия: точечное чтение исходников, `rg`, детерминированное извлечение текста, тесты и генерация OpenAPI, минимум повторных ревью. Настройки модели Codex не меняются; helper не заменяет основную сессию.
