# Публичные источники и навыки, 1.4

> Исторический документ до упрощения 1.7. Актуальный состав и ограничения: [SIMPLIFIED-1.7.md](SIMPLIFIED-1.7.md). Упомянутые здесь LLM, GitHub, ATS-заметки и проценты больше не входят в runtime.

## Импорт в MAX

После согласия на отклик кандидат присылает одну HTTPS-ссылку вместо текста. Задание сохраняется в БД; отдельный worker читает источник **вне транзакции обработки MAX-события**. Кандидат видит предупреждение, предпросмотр и постраничный полный текст. Только кнопка «Использовать для отклика» передаёт текст/оригинал PDF работодателю. Отмена не создаёт отклик.

Поддерживаемые форматы:

| Источник | Ссылки | Ограничения |
| --- | --- | --- |
| GitHub | `https://github.com/USER`, `https://github.com/USER/REPO` | До 5 последних публичных репозиториев, описания и языки файлов. Форки помечаются. Без email, закрытого кода, коммитов, выполнения кода или оценки личности |
| Яндекс Диск | `https://disk.yandex.ru/d/ID`, `/i/ID`, `https://yadi.sk/d/ID` | Только публичный PDF, официальный resolver `/v1/disk/public/resources/download`, ограниченные CDN `*.disk.yandex.*` и `*.storage.yandex.net` |
| Google Drive | Отключено в 1.5 | До согласования с организаторами или реализации через официальный документированный API |
| Облако Mail.ru | Отключено в 1.5 | FAQ п. 6 не допускает закрытые/частные API. Внутренний dispatcher удалён, сетевых запросов к Mail больше нет |

Подключение внешнего диска не означает авторизацию к аккаунту. Приватные ссылки, HTML вместо PDF и сканы отклоняются. 28.09.2026 три предоставленные пользователем ссылки (Google, Yandex, Mail) успешно прочитаны через бэкенд без входа: каждый PDF 90 313 байт, извлечено 4 893 символа. Проверялась загрузка/извлечение, не отправка отклика в MAX. Само резюме, его текст, имена и share-link не сохранены в Git или публичном отчёте и не передавались внешним LLM. Не делайте настоящее резюме общедоступным ради тестирования.

27.09.2026 живой запрос к `https://github.com/TheEdfog` успешно прочитал пять публичных репозиториев: max-hackathon-bot, methane-forecasting, neural-fca, retail-streaming-lakehouse, study-cards-api. Это проверка доступности импорта, **не оценка квалификации**. Кандидатский импорт ограничен описаниями и языками; отдельный обзор работодателя, добавленный в 1.4, умеет читать README.

## Отдельная кнопка GitHub у работодателя

Карточка кандидата - «GitHub-обзор» - «Прочитать GitHub». Первое открытие только показывает ссылки из резюме/ответов. Никакого поиска человека по имени и произвольного прикрепления чужого аккаунта. До нажатия кнопки сетевых запросов нет.

Обзор: профиль (login и bio, без полей email/location), до пяти недавно обновлённых публичных репозиториев, описание, основной язык, отметки fork/archive и выдержка README до 2 000 символов. Ссылки/email в текстах скрываются, но это не универсальный обезличиватель произвольных сведений автора. Не читаем деревья/код/коммиты/приватные репозитории и ссылки из README, не исполняем JS, не вызываем LLM. Число звёзд и подписчиков не используется как оценка. Строки README - чужие утверждения, не инструкции или проверенные факты.

До семи основных API-запросов, общий бюджет reader - восемь с учётом redirects; README JSON до 512 КБ, декодированный текст до 50 КБ. Кэш результата - 24 часа на отклик, кэш ошибки - до 15 минут, максимум 5 новых обзоров/час/работодателя. Повторное открытие использует кэш. Worker читает сеть вне транзакции; lease восстанавливается после рестарта. Отзыв отклика удаляет обзор и отменяет связанные уведомления. Просроченный обзор сразу скрыт, физическая очистка выполняется worker после запуска; уже доставленные сообщения/backup имеют отдельный регламент.

28.09.2026 живой обзор TheEdfog получил пять репозиториев и пять выдержек README. LLM-запросов: 0. Это дополнительная вкладка, **не вход для модели соответствия**.

## Границы безопасности и хранения

- Перед подтверждением кандидат может добавить описание своего опыта или заменить весь импортированный текст. Дополнение помечается отдельно, исходный PDF сохраняется. Замена текста удаляет PDF из черновика и будущего отклика: убранные кандидатом сведения не должны попасть работодателю через исходный файл. Старые кнопки подтверждения после изменения недействительны; текст нужно подтвердить заново. Предыдущие серверные предпросмотры очищаются, уже доставленные сообщения MAX не удаляются.
- HTTPS/443, allowlist конкретных vendor-host/CDN; отказ при userinfo, backslash, приватных DNS-адресах и перенаправлении на другой хост. Не допускается загрузка произвольного URL или доступ к metadata/internal API.
- Без Authorization/cookies, без системного proxy из окружения. Ответы источника - данные, не команды.
- До 4 переходов, 8 HTTP-запросов на импорт, общий контроль времени чтения 25 секунд (DNS и отдельные сетевые таймауты могут добавить задержку), PDF до 5 МБ. Два одновременных чтения на процесс. GitHub 403/429 не обходятся ротацией ключей или адресов.
- MAX: до 5 импортов за час на пользователя, до 100 незавершённых заданий. Черновики живут 24 часа; worker чистит их после истечения, включая ожидающие предпросмотры в outbox. При выключенном процессе очистка произойдёт после запуска. Отмена/использование очищает URL, текст и PDF задания сразу. Уже доставленные сообщения MAX и backup требуют отдельного регламента.
- Lease 2 минуты позволяет продолжить зависшее задание после перезапуска. Перед публикацией результата повторно проверяется текущий пользовательский шаг; отменённый или устаревший импорт не завершает отклик.
- Original PDF хранится BLOB в той же закрытой SQLite и удаляется с отзывом отклика. Масштабирование на object storage с отдельным retention пока не сделано.
- Текст PDF длиннее 20 000 символов отклоняется целиком: незаметного обрезания сведений кандидата нет. Предложите сокращённое резюме или вставьте нужный текст вручную.

## Сопоставление навыков

Код Вадима содержит нормализацию и связи навыков. В новом ядре переиспользованы нормализация и объяснимые направленные связи:

- питон/питоне/питоном = Python; postgres/postres/постгрес = PostgreSQL;
- PostgreSQL, MySQL, MSSQL, SQLite, ClickHouse дают **косвенный признак** SQL;
- SQLAlchemy / Entity Framework дают косвенный признак ORM;
- GitHub Actions / GitLab CI / Jenkins дают косвенный признак CI/CD;
- обратные выводы не делаются, произвольное нечёткое исправление похожих слов не включено.

Общий словарь извлечения и сопоставления: 152 канонических навыка, 368 вариантов написания, 13 групп направленных связей на дату версии 1.4. Это не только IT: управление проектами/продуктом, переговоры, анализ/сбор требований, user stories, roadmap, CustDev, продуктовая аналитика, продажи, CRM, деловая коммуникация. Наличие soft skill означает только утверждение кандидата, а не проверенное качество. Ручные требования поддерживаются, но для неизвестной словарю формулировки нет универсального семантического распознавания. Общее слово API не приравнивается к REST API.

Правила оценки и отличия от Вадима: [VADIM-REVIEW.md](VADIM-REVIEW.md).

API возвращает `direct_covered` и `inferred` отдельно; `covered` и `coverage` включают оба вида признаков. `state=inferred` содержит исходную цитату и `related` с технологией-основанием, также порождает уточнение в пределах лимита 3. Явное отсутствие опыта или неопределённая формулировка не заменяются положительным предположением. Это покрытие **сведениями**, не процент квалификации или вероятность найма.

Ранние сообщения текущего чата и чата «Опубликовать сайт в Yandex Cloud» повторно просмотрены: подтверждены исходный `cvservice_web` и его ТЗ `docs/TZ_CVService_Web_v3.docx`. Полный диплом в этих сообщениях не найден; его повторное чтение не заявляется.
