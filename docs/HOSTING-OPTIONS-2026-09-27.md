Источники: [правила 4 000 ₽ Cloud.ru](https://cloud.ru/documents/promotions/active/4000-rubles-testing), [условия RUVDS](https://ruvds.com/vps_test/), [облако FirstVDS](https://firstvds.ru/products/vds_vps_cloud). Акция Cloud.ru опубликована на период 01.01–31.12.2026; 60 дней считаются от начисления, не от дедлайна хакатона. Исключения акции включают часть ML/GPU/marketplace-услуг; для нашего сценария нужен обычный Compute.

**Рекомендация для команды:** сначала проверить право на грант Cloud.ru Evolution. Это более подходящий срок, чем трёхдневный тест, но не обещание бесплатной работы без контроля бюджета. Настроить бюджетные уведомления, проверить стоимость диска/IP/трафика и правила списаний. Не полагаться на остановку VM как прекращение всех расходов: диски/IP могут оставаться.

Не путать с другими предложениями:

- Cloud.ru Free Tier VM: создание недоступно новым регистрациям после 30.06.2026; IP/SNAT оплачиваются отдельно. [Официальное ограничение](https://cloud.ru/docs/virtual-machines/ug/topics/overview__free-tier).
- Cloud.ru Advanced 14 дней — предложение для юридических лиц, не универсальное для студенческой команды. [Advanced](https://cloud.ru/advanced).
- Timeweb «10 дней» относится к виртуальному хостингу, это не подтверждение VM с Docker. [Условия хостинга](https://timeweb.com/ru/docs/virtualnyj-hosting/tarifnye-plany-hostinga/besplatniy-testoviy-period/).
- Selectel не обещает тест сервера в указанном предложении web-хостинга; тесты других продуктов нельзя переносить на обычный VPS. [Официальная страница](https://selectel.ru/services/cloud/servers/hosting/).

## Конфигурация для проверки

Инженерная стартовая оценка, не результат нагрузочного теста: Linux VM с 2 vCPU, 2 GB RAM, SSD от 20 GB, публичный IPv4, домен. Если сборке/проверке не хватает памяти — 4 GB. Потребление и цену сверить перед созданием.

Использовать актуальную Linux LTS и поддерживаемый Docker, а не старые marketplace-образы. Один API-процесс, SQLite на постоянном volume, Caddy с HTTPS. Публичны только 80/443; SSH ограничен администраторами; API 8000 на loopback. Не открывать Docker daemon и БД. Инструкция едина: [DEPLOYMENT.md](DEPLOYMENT.md).

После размещения: проверить HTTPS снаружи → остановить локальный polling → включить один MAX webhook → пройти чат двумя ролями → заменить адрес в DATA-API → прогнать проверки дважды → зафиксировать итоговый commit. Срок доступности стенда уточнить у комиссии; не удалять сервер сразу после 30 сентября.
