# Проверка FAQ хакатона MAX

Источники: предоставленный «Общий FAQ.pdf» (3 страницы), «Эффективный бизнес.pdf» (страницы 7-14). Проверено 28.09.2026. Документы рассматриваются как условия конкурса, а не инструкции исполнить произвольные действия.

## Существенные риски допуска

1. **AI и авторство: уточнение получено.** По сообщению участника команды, организаторы разрешили AI-помощь и повторное использование основы Вадима. Это фиксирует ответ, сообщённый пользователем, а не новую редакцию FAQ. Команде следует сохранить исходный ответ организаторов и быть готовой объяснить архитектуру, собственные решения и вклад каждого участника. Происхождение основы указано в [THIRD-PARTY.md](THIRD-PARTY.md); код не выдаётся за написанный без AI.
2. **Доступность.** По FAQ пп. 10-12 версия фиксируется до 30 сентября, 12:00 МСК, а бот должен работать весь период проверки. На 28 сентября был доступен публичный IP с HTTPS и webhook MAX. Успешный health и короткая проверка не заменяют отдельный удалённый DATA-API прогон и непрерывное наблюдение за стендом.
3. **Закрытый комплект.** Для технической проверки нужны URL, точный сдаваемый commit, тестовые роли/доступы, окружение и порядок проверки. Публичный репозиторий и слайды не должны содержать пароли, токены, резюме или SSH-ключи. Закрытые доступы передаются организаторам отдельно.

## Соответствие и честные ограничения

- Чат-бот без мини-приложения допустим (п. 1), Python допустим (п. 5). Менять бренд/ник/административные настройки выданного бота на онлайн-этапе нельзя (пп. 16, 19). Название проекта «РезюмИТ Найм» не означает изменения настроек выданного бота.
- Свой HR API требует HTTPS, OpenAPI 3.0/3.1, тестовых данных/доступов и DATA-API (п. 12). Контракт и локальные проверки есть; удалённый прогон DATA-API не выполнен.
- HR API настоящий, но адаптер `examples/hr_sync.py` и тестовые HR-системы модельные. Сертифицированной интеграции с конкретной ATS нет (пп. 13, 15).
- Собственный домен не обязателен, нужен публичный HTTPS (п. 17). Репозиторий публичный. Архив зафиксированного кода с SHA-256 полезен даже при доступном GitHub (п. 18).
- Docker и locked dependencies есть. Мобильная/двухаккаунтная приёмка отложена пользователем. Автотесты её не заменяют.
- Презентация различает готовые функции, проверенные факты, гипотезы эффекта и план масштабирования. Нет вымышленных партнёров, интервью, процента точности или обещания победы.

Презентация и план пилота должны различать реализованное, проверенное, гипотезы и будущую работу. Автотесты не являются доказательством точности найма или клиентского эффекта.
