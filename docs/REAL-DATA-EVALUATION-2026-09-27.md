# Локальная проверка на реальном материале

Источник — предоставленная владельцем переписка с рекрутинговым ботом. Сам файл, имена, контакты и тексты ответов **не публикуются** и не передаются внешним LLM. В отчёте только агрегаты. Это функциональная проверка на малом материале, не независимый benchmark качества найма.

Воспроизводимый локальный запуск, если у проверяющего есть разрешённая копия:

```sh
python scripts/evaluate_interview.py --transcript PATH_TO_PRIVATE_TRANSCRIPT
```

Скрипт без сетевых вызовов и отправки MAX: три реальных описания вакансий и один профессиональный профиль из ответов пользователя; БД в памяти, синтетические аккаунты. Полного набора реальных резюме здесь нет. Уточняющие ответы для функционального цикла — синтетические пропуски, а не выдуманные ответы реального человека.

| Проверка | До расширения словаря | После |
| --- | --- | --- |
| Извлечённые требования в 3 описаниях | 1 / 1 / 1 | 6 / 2 / 2 |
| Пропуски в вручную выбранном списке явно названных технологий | ETL, Spark, Hadoop, Greenplum | В выбранном списке нет |
| Вопросы по навыкам | Ограничение ≤3 | 3 / 2 / 2 |
| Отклик → ответы → приглашение → подтверждение → отзыв | Пройдено | Пройдено для 3 вакансий |
| Цитаты в карточке — подстроки исходного профессионального текста | Проверено | Проверено |
| Передача исходного материала внешним сервисам | Нет | Нет |

Добавлены Spark/PySpark, Hadoop, Greenplum, ETL/ELT, pandas, качество данных/DQ. Упоминание PySpark не доказывает Python или Hadoop; отрицание не превращается в положительный опыт. Автотесты проверяют эти границы. Наличие дословной цитаты подтверждает её происхождение, не истинность опыта.

## hh.ru

27 сентября поиск вакансий и поиск резюме через `api.hh.ru` вернули HTTP 403, `forbidden`. Повтор с согласованным пользователем контактным email в `User-Agent` и `HH-User-Agent` результата не изменил. Email не включён в код или этот отчёт. Такой ответ сам по себе не доказывает конкретную причину отказа.

[Официальная документация](https://api.hh.ru/openapi/redoc) задаёт заголовок с названием приложения и контактной почтой; email не заменяет OAuth и права доступа к защищённым методам. Поиск резюме имеет ограничения авторизации/доступа. Ограничения не обходились, массового сбора персональных данных не было.

Для измерения качества перед защитой нужен разрешённый обезличенный набор из нескольких независимых профилей и вакансий, с разметкой рекрутера и отложенной выборкой. На текущих трёх описаниях нельзя заявлять «точность 100%», устойчивость к любым резюме или доказанную экономию времени.
